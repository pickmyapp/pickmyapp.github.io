How to Fix Excel Running Slow on Windows 11 (2026): 9 Fixes That Work

  • Software Tutorials
  • Published Oct 13, 2026
  • Updated: October 2026
  • 12 min read
  • By PickMyApp Research Team
Quick answer

The three fixes that resolve most slow-Excel cases on Windows 11: (1) disable faulty add-ins by testing in Safe Mode (Win + R, then excel /safe), (2) turn off hardware graphics acceleration under File > Options > Advanced > Display, and (3) switch calculation to manual on formula-heavy workbooks (Formulas > Calculation Options > Manual). If only one file is slow, the workbook itself is bloated — clear conditional formatting, reset the used range, and save as .xlsb.

Excel running slow on Windows 11 is one of the most common Office complaints. The good news: the causes are well understood. In almost every case the slowdown comes from one of five things — a misbehaving add-in, GPU rendering conflicts, constant recalculation, a bloated workbook, or a damaged Office install — and each has a concrete fix. Diagnose first (two minutes), then apply the fixes that match your symptoms.

Step 0: Diagnose before you fix

Two minutes of diagnosis saves an hour of random tweaking. Answer these three questions:

  • Is it one file or every file? Open a blank workbook and type in a few cells. If the blank workbook is fast but your real file crawls, the problem is the workbook (Fix 3 and Fix 4). If every file is slow, the problem is Excel or Windows (Fix 1 and Fix 2).
  • Is it fast in Safe Mode? Press Win + R, type excel /safe, and press Enter. If your file suddenly behaves, an add-in is the culprit (Fix 1).
  • What does Task Manager say? Press Ctrl + Shift + Esc and watch CPU and memory while Excel lags. One CPU core pinned at 100% points to recalculation (Fix 3). Memory climbing toward 2 GB on 32-bit Excel points to the memory ceiling (Fix 5).

Write down what you found. Every fix below maps to one of these symptoms.

Fix 1: Run Safe Mode and disable bad add-ins

Add-ins are the most common cause of Excel-wide slowness. COM add-ins from PDF tools, antivirus suites, and data connectors load with every Excel session, and one poorly written add-in can add seconds to every action. Microsoft's own support engineers start here, and so should you.

Confirm it: launch Excel in Safe Mode (Win + R, type excel /safe, press Enter) — or hold Ctrl while clicking the Excel icon and accept the prompt. If Excel feels normal, an add-in is guilty.

Find the culprit:

  1. In normal Excel, go to File > Options > Add-ins.
  2. At the bottom, set the Manage dropdown to COM Add-ins and click Go.
  3. Uncheck everything and click OK, then restart Excel normally.
  4. Re-enable add-ins one at a time, restarting Excel after each, until the slowness returns. The last one you enabled is the problem — leave it off or check the vendor's site for an update.

Repeat the same process for the Excel Add-ins entry in the Manage dropdown. Common offenders include PDF printer add-ins, antivirus Office plugins, and old data-analysis toolbars you installed years ago and forgot about.

Fix 2: Turn off hardware graphics acceleration

Excel uses your GPU to render the interface, and on Windows 11 this is a frequent source of lag — scrolling stutters, typing delays, and charts that redraw slowly — especially with integrated graphics or outdated display drivers. Disabling it forces Excel to render with the CPU, which is often faster in practice on affected systems.

  1. Open Excel and go to File > Options > Advanced.
  2. Scroll to the Display section.
  3. Check Disable hardware graphics acceleration.
  4. Click OK and restart Excel.

If the lag disappears, leave it off — you lose nothing except GPU-rendered animations. Also update your display driver (Intel, AMD, or NVIDIA) through Windows Update or the manufacturer's site, because the underlying conflict is usually a driver issue; a fixed driver may let you re-enable acceleration later.

Fix 3: Switch to manual calculation and tame volatile functions

If Excel freezes for a second or two every time you edit a cell, you are watching recalculation happen. Excel recalculates every formula in the workbook on each change by default. On a workbook with thousands of formulas, that turns typing into a slideshow.

Switch to manual calculation

  1. Go to the Formulas tab and click Calculation Options.
  2. Select Manual.
  3. Press F9 whenever you want Excel to recalculate.

Typing becomes instant because Excel stops recalculating after every keystroke. Respect the tradeoff: formulas do not update until you press F9, so press F9 before trusting any number, and switch back to Automatic when you finish editing a heavy model.

Replace volatile functions

Some functions recalculate on every change no matter what. These volatile functions — OFFSET, INDIRECT, NOW, TODAY, RAND, RANDBETWEEN — are the reason a few hundred careless formulas can make a whole workbook feel broken.

  • Replace OFFSET with INDEX for dynamic ranges — INDEX is not volatile and does the same job in most cases.
  • Replace INDIRECT with direct sheet references or CHOOSE where possible.
  • Replace NOW() and TODAY() used as timestamps with a pasted static value if the date does not need to update live.
  • Press Ctrl + [ on a formula cell to trace its precedents and find which volatile calls feed the slowdown.

Quick fact: also check File > Options > Advanced > Formulas and confirm multi-threaded calculation is enabled — it lets Excel use all your CPU cores for recalculation instead of one.

Fix 4: Shrink the bloated workbook

When one specific file is slow, the file itself is almost always the problem. Workbooks accumulate invisible weight: formatting applied to entire columns, conditional formatting rules copied down thousands of rows, uncompressed images, and links to files that no longer exist. Here are the bloat culprits, roughly in order of impact:

The most common sources of workbook bloat and how to clear each one.
CulpritWhy it slows ExcelFix
Conditional formattingRules evaluated on every recalculation across large rangesHome > Conditional Formatting > Clear Rules on sheets that do not need it; keep rules to the smallest range possible
Oversized used rangeExcel remembers formatting far below your real dataPress Ctrl + End — if it lands far past your data, delete the excess rows and columns, then save
Full-column referencesFormulas like SUM(A:A) force Excel to scan a million rowsReplace with bounded ranges (A1:A5000) or Excel Tables (Ctrl + T), which expand automatically
Uncompressed imagesEmbedded photos bloat file size and redraw timeSelect a picture, then Picture Format > Compress Pictures, and apply to all pictures
External linksExcel tries to reach dead network paths on open and recalcData > Edit Links — break links to files you no longer use

After cleaning, save in binary format: press F12, choose Excel Binary Workbook (*.xlsb), and save. The .xlsb format stores the same content — formulas, formatting, charts, even macros — in a compact binary layout that opens and saves noticeably faster. Keep an .xlsx copy only if you share with third-party tools that cannot read binary workbooks.

Fix 5: Repair Office, update everything, and check 32-bit vs 64-bit

If Excel is slow across all files and Safe Mode did not help, the installation itself may be damaged or outdated.

Run the Office repair tool

  1. Open Settings > Apps > Installed apps (press Win + I first).
  2. Find Microsoft 365 or Microsoft Office, click the three dots, and choose Modify.
  3. Choose Quick Repair and click Repair — it takes a few minutes and keeps your files and settings.
  4. If the problem persists, repeat and choose Online Repair, which re-downloads damaged components from Microsoft's servers.

Install updates

Run Windows Update (Settings > Windows Update) and, inside any Office app, File > Account > Update Options > Update Now. Bad Office builds cause performance regressions often enough that many "Excel suddenly got slow" threads end with an update.

Make sure you are on 64-bit Excel

Go to File > Account > About Excel and look at the top line. If it says 32-bit, you have a hard ceiling: 32-bit Excel is limited to 2 GB of virtual memory no matter how much RAM your PC has. The 64-bit version removes the ceiling almost entirely. Unless you depend on ancient 32-bit-only COM add-ins, reinstall the 64-bit version.

Fix 6: Windows 11-specific settings

A few slowdowns are specific to how Windows 11 interacts with Office. Work through these if the generic fixes did not fully resolve it:

  • Update your GPU driver. Windows 11's display stack is pickier than Windows 10's. Get the latest driver from Intel, AMD, or NVIDIA directly — display-driver bugs cause a large share of Excel rendering lag.
  • Set the power mode to Best performance. On laptops, Windows 11 throttles the CPU on battery-friendly plans. Go to Settings > System > Power & battery and set Power mode to Best performance while plugged in.
  • Fix the default printer. Excel queries the default printer at startup and sometimes during recalculation. If your default is a network printer that no longer responds, Excel hangs waiting for it. Go to Settings > Bluetooth & devices > Printers & scanners and set Microsoft Print to PDF as the default.
  • Clear temporary files. Press Win + R, type %temp%, press Enter, and delete what Windows allows. Corrupted temp files cause mysterious Office slowdowns that nothing else explains.
  • Close background resource hogs. Browsers with dozens of tabs, Teams, and antivirus scans compete for the same CPU and memory Excel wants. Check Task Manager's Processes tab sorted by CPU while Excel lags.

When it is the hardware, not Excel

Sometimes Excel is slow because the PC is genuinely underpowered. Signs: the whole system lags (not just Excel), Task Manager shows memory above 85% with Excel open, and the file is hundreds of megabytes with Power Pivot models or millions of rows. In that case software tweaks have limits — an SSD, 16 GB of RAM, and a modern multi-core CPU each make a real difference. But try every fix above first: most slow-Excel complaints on modern hardware are software problems wearing a hardware disguise.

Frequently asked questions

Why is Excel slow on Windows 11 but was fine on Windows 10?

The usual culprits are display-related: outdated GPU drivers clashing with Excel's hardware graphics acceleration, and a stale default printer that Excel queries at startup. Disabling hardware graphics acceleration and resetting the default printer fix most of these cases.

Does more RAM fix slow Excel?

Sometimes, but it is rarely the first thing to try. If you are running 32-bit Excel, you are capped at 2 GB of virtual memory no matter how much RAM is installed — switching to 64-bit Excel removes that ceiling entirely. Above 8 GB of RAM, slow Excel is almost always caused by the workbook itself: volatile formulas, add-ins, or file bloat.

Should I use 32-bit or 64-bit Excel?

Use 64-bit Excel unless you depend on old 32-bit-only COM add-ins. The 32-bit version is limited to 2 GB of virtual memory, which large workbooks exhaust quickly. The 64-bit version has effectively no memory ceiling for spreadsheet work. Check yours under File, then Account, then About Excel.

Will saving as .xlsb lose anything in my workbook?

No. The binary .xlsb format stores everything a normal .xlsx file does — formulas, formatting, charts, and VBA macros — but in a compact binary layout that opens and saves faster and produces a smaller file. The only downside is that some third-party tools cannot read .xlsb files, so keep an .xlsx copy if you share with systems that might.

Why does Excel freeze for a few seconds every time I type one character?

That pattern points to volatile functions or automatic calculation on a large workbook. Functions like OFFSET, INDIRECT, NOW, and TODAY recalculate on every change, so each keystroke triggers a full recalculation. Switch to manual calculation mode (Formulas tab, then Calculation Options, then Manual) and replace volatile functions where you can.

Conclusion

Slow Excel on Windows 11 is almost never mysterious once you diagnose it: test in Safe Mode to catch bad add-ins, disable hardware graphics acceleration to rule out GPU conflicts, and switch heavy workbooks to manual calculation. If only one file is slow, clean the workbook — conditional formatting, the used range, and full-column references are the usual suspects. Work the list in order, and blame the hardware only after the software fixes have had their say.
