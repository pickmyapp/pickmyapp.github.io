how to speed up outlook on windows 11 (2026)

  • Software Tutorials
  • Published Oct 16, 2026
  • Updated: October 2026
  • 9 min read
  • By PickMyApp Research Team
Quick answer

Outlook on Windows 11 is slow because of one of four things: a misbehaving add-in, an oversized offline mailbox cache, a broken Windows Search index, or a corrupted data file or profile. Identify whether you're running the new Outlook or classic Outlook, then test Safe Mode (classic) or repair/reset the app (new Outlook), trim your cache, and rebuild the index. Most people fix it in under 30 minutes without losing a single email.

If Outlook takes forever to open, freezes when you switch folders, or shows "Not Responding" every time you search, you're not imagining it — and you don't need to reinstall Windows. On Windows 11, slow Outlook almost always traces back to one of four local bottlenecks: add-ins, an oversized offline cache, Windows Search indexing, or a damaged data file or profile. The tricky part in 2026 is that Microsoft now ships two different Outlooks — the new Outlook for Windows and classic Outlook — and the right fix depends on which one you have. This guide covers both, in the order a help-desk technician would actually test them.

Step 0: Which Outlook are you actually running?

Before touching anything, identify your version. Open Outlook and look at the top bar: if you see a File tab with File > Options, you're in classic Outlook (part of Microsoft 365/Office desktop). If there's no File tab and settings live under a gear icon, you're in the new Outlook for Windows, the lighter Store-based app Microsoft has been rolling out.

The new Outlook for Windows does not support COM add-ins at all — only modern web add-ins — according to Microsoft's own support documentation. That single design difference means classic Outlook is far more vulnerable to add-in slowdowns, while the new Outlook is more vulnerable to sync and cache issues.

Write one sentence describing your slowdown: "I'm on classic Outlook and it's slow when I start it" or "I'm on new Outlook and search is slow." Knowing the version and the exact slow moment saves you from applying fixes to the wrong problem.

Step 1: The 2-minute server-vs-PC test

If you use Microsoft 365 or Outlook.com, open Outlook on the web in your browser and repeat the slow action — open the inbox, run the same search, open a message. If the web version is also slow, the problem is on the network or service side: try a different connection (disconnect from a corporate VPN and test again) or wait for Microsoft to resolve the issue. If the web version is fast, your local Outlook setup is the bottleneck, and the steps below will fix it.

Step 2: Update Outlook and restart (don't skip this)

Unfinished updates are one of the most common "sudden" slowdowns. In classic Outlook, go to File > Office Account > Update Options > Update Now. In the new Outlook, open the Microsoft Store > Library > Get updates. Then restart Windows properly: Start > Power > Restart — and check Task Manager (Ctrl + Shift + Esc) to kill any lingering Outlook process stuck in the background.

One note for 2026: Microsoft removed the Support and Recovery Assistant (SaRA) command-line utility from supported Windows updates released on and after March 10, 2026, recommending the Get Help tool instead. If an older guide tells you to "run SaRA," you may not have it installed — this guide sticks to built-in tools that are still available.

Also check Task Manager (Ctrl + Shift + Esc) after closing Outlook to make sure no lingering Outlook process is stuck in the background. A half-closed Outlook process can make the next launch crawl while it fights over your data files.

Step 3: Hunt down slow add-ins

Add-ins are the number one cause of slow Outlook startup and laggy folder switching. Meeting schedulers, CRM connectors, PDF tools, and even some antivirus integrations hook into nearly every Outlook action — and a single greedy one can stall the whole app.

Classic Outlook: the Safe Mode test

Close Outlook, press Win + R, type outlook.exe /safe, and press Enter. Use Outlook for two minutes: open emails, switch folders, run a search. If Safe Mode feels fast, an add-in is very likely the cause — Safe Mode starts Outlook with all add-ins disabled.

Find the culprit one at a time

Open Outlook normally and go to File > Options > Add-ins. At the bottom, set the Manage dropdown to COM Add-ins and click Go. Uncheck everything you don't need today — start with non-Microsoft add-ins — click OK, and restart Outlook. If Outlook becomes fast, re-enable add-ins one at a time (restarting after each) until the slowdown returns. That's your culprit; leave it disabled.

Microsoft even surfaces this for you: add-ins that drag down performance appear under File > Slow and Disabled COM Add-ins, with the average delay each one causes listed next to it. If something appears there, disable it and see if your startup time drops.

New Outlook: web add-ins only

The new Outlook supports only web add-ins, which run sandboxed and generally cause fewer performance problems — but they can still pile up. Open the new Outlook's settings (gear icon), look for Add-ins, and remove any you don't recognize or no longer use. If the app still feels slow, try Settings > Apps > Installed apps > Outlook > Advanced options > Repair first, then Reset (you'll sign back in afterward). Clearing the new Outlook's local cache lives under %localappdata%\Microsoft\Olk — deleting its contents with the app closed forces a fresh resync.

Don't just disable an add-in you no longer use — uninstall it. Disabled add-ins still appear in Outlook's startup checks; uninstalled ones don't.

Step 4: Shrink what Outlook caches locally

Classic Outlook in Cached Exchange Mode keeps a local copy of your mailbox in an OST file. When that file balloons — years of email, huge attachments, shared mailboxes piling on — everything from startup to folder switching slows down. IT guides commonly flag OST files above roughly 50 GB, or folders holding more than 100,000 items, as the zone where hangs and sync errors start appearing.

Shorten the offline mail window

Go to File > Account Settings > Account Settings, select your main account, click Change, and move the "Mail to keep offline" slider to a shorter window — 6 or 12 months is usually plenty. Restart Outlook. Older mail stays on the server and is still searchable; it just isn't cached locally. This single change is the biggest performance win for large mailboxes.

Clean up and compact

Use File > Info > Tools > Mailbox Cleanup and empty Deleted Items. Then find oversized messages by typing messagesize:>5 MB in the search box and dealing with the worst offenders (save attachments elsewhere, then delete). Finally, compact the data file: File > Account Settings > Account Settings > Data Files, select your data file, Settings > Compact Now. Outlook only compacts when there's enough unused space, so this works best right after a real cleanup.

For more ways Windows itself can drag Office apps down, see our guide on fixing Excel running slow on Windows 11 — many of the same background-process culprits apply.

Step 5: Fix slow search by rebuilding the index

If search returns missing or partial results — or typing in the search box locks the app up — the Windows Search index for Outlook is probably incomplete or corrupted. In classic Outlook, go to File > Options > Search > Indexing Options and confirm Microsoft Outlook is included. Then open Control Panel > Indexing Options > Advanced > Rebuild.

Two things to know: Windows only indexes Outlook data while Outlook is open, and searches may be incomplete until indexing finishes. Leave Outlook open and your PC powered on until the rebuild completes — on a large mailbox this can take hours, so starting it before lunch or overnight is the smart move.

Step 6: Repair the data file or rebuild the profile

If Outlook freezes at "Loading Profile" or hangs no matter what you've tried, the data file or profile itself may be damaged.

PST users: run the Inbox Repair Tool

POP accounts and local archives use PST files. Close Outlook, run SCANPST.EXE, select your PST, click Start, then Repair. You may need to run it multiple times for stubborn errors. Back up the file first — and if you keep years of mail in one PST, consider splitting "active" mail and "archive" into separate PSTs and compacting regularly.

Exchange users: rebuild the OST

The OST is just a local cache of what's on the server (Microsoft 365/Exchange). Close Outlook, rename or delete the OST, and Outlook recreates it on next launch. Do not do this if you might have local-only data — when in doubt, back the file up first.

The nuclear option: a fresh profile

Close Outlook, open Control Panel, search for Mail (Microsoft Outlook), click Show Profiles > Add, name the new profile, and add your email account. A fresh profile is the fastest way to confirm whether the problem was corruption in the old one.

Keep Outlook fast going forward

A little maintenance prevents the creep back to slowness. Weekly: empty Deleted Items, clear stuck Outbox items, and uninstall (not just disable) add-ins you no longer use — security add-ons like AI email scanners are worth keeping only if you actually rely on them. Share links instead of emailing attachments around to keep mailbox size down.

Monthly: run Mailbox Cleanup followed by Compact Now, and audit shared mailboxes — remove any that auto-open but you rarely read. If you manage a team, standardize a "known-good" add-in list and strip everything else by default; your help desk will thank you. Running Outlook on an older machine? Heavy background AI workloads can also steal resources — our guide to running AI models locally on Windows covers how to keep GPU-heavy tasks from choking the rest of the system.

Do this now (under 30 minutes)

Run the server-vs-PC test, update and restart, kill lingering processes in Task Manager, then do the Safe Mode add-in check (classic) or app Repair (new Outlook). Shorten your offline mail window to 6–12 months. These four steps fix the vast majority of slow-Outlook cases.

Save for later

Rebuilding the search index and recreating your profile or OST are heavier operations — do them when the quick steps don't resolve things, and set them running when you don't need the PC for a while. A full Office Online Repair is the last resort before calling IT.

Frequently asked questions

Why is Outlook so slow on Windows 11 all of a sudden?

Sudden Outlook slowdowns are usually caused by a newly installed or updated add-in, a mailbox that crossed a size threshold, a stuck Windows Search index, or a Windows update that needs a restart to finish. Test the theory by opening classic Outlook in Safe Mode (outlook.exe /safe) — if it runs fast there, an add-in is the culprit.

Is the new Outlook for Windows faster than classic Outlook?

The new Outlook for Windows is a lighter Store app that launches faster on modest hardware and supports only modern web add-ins, so it sidesteps many classic add-in slowdowns. Classic Outlook is still the better choice for power users with huge mailboxes, complex rules, or COM add-ins their business depends on.

How big can an OST file get before Outlook slows down?

Microsoft documentation and IT support guides generally treat OST files above 50 GB, or folders holding more than 100,000 items, as the zone where slowdowns, hangs, and sync errors become common. Shrinking the "Mail to keep offline" window is the fastest way to bring an OST back down to a healthy size.

Will rebuilding the Outlook search index delete my emails?

No. Rebuilding the search index only rebuilds the search catalog; your emails stay in your mailbox and data files. Searches may return incomplete results until indexing finishes, so keep Outlook open and your PC powered on while it runs.

Does disabling add-ins actually speed up Outlook?

Yes — add-ins are the single most common cause of slow Outlook startup and laggy folder switching, especially in classic Outlook where COM add-ins hook into nearly every action. If Outlook is fast in Safe Mode but slow in normal mode, an add-in is almost certainly responsible.

Conclusion

A slow Outlook on Windows 11 is almost never a mystery — it's an add-in, a bloated cache, a broken index, or a damaged profile, and each one has a direct fix. Start with the cheap checks (version, server test, updates, Task Manager), isolate add-ins with Safe Mode, shrink your offline cache window, and rebuild the index or profile only when the quick wins don't land. Do them in that order and you'll spend 30 minutes troubleshooting instead of a weekend reinstalling.

A note from the author: I've seen more Outlook slowdowns "fixed" by a simple restart-after-update than by any exotic repair tool. If you take one habit from this guide, make it the weekly Deleted Items purge — it costs ten seconds and keeps the 50 GB monster at bay.
